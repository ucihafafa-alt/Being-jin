Эрүүл Бие — Эрүүл Жин систем /FLAT хувилбар/

Энэ хувилбарт assets хавтас байхгүй.
Бүх файл болон 3 зураг нэг дор буюу repository-ийн хамгийн гадна талд байрлана.

GitHub дээр оруулахдаа эдгээрийг бүгдийг нь нэг дор upload хийнэ:
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- hero.jpg
- balance.jpg
- energy.jpg
- README.txt

Зурагнуудыг тусдаа assets хавтас руу хийх шаардлагагүй.
style.css болон sw.js дотор зурагны замыг шууд hero.jpg, balance.jpg, energy.jpg гэж заасан.

GitHub Pages:
1. Repository > Settings > Pages
2. Source: Deploy from a branch
3. Branch: main, Folder: /root
4. Save

Анхаарах:
- Энэ систем мэдээллийг серверт хадгалахгүй.
- Хэрэглэгч өөрөө бөглөөд BMI, урьдчилсан үнэлгээ, сонгосон багцын чиглэлээ харна.
- Бүрэн 1/2/3 сарын хоолны төлөвлөгөө төлбөр баталгаажсаны дараа гаргах зориулалттай.
- Систем өвчин оношлохгүй, эмчилгээний заавар бичихгүй. Халдварт бус өвчлөлийн болзошгүй эрсдэлийн дохиог тайлбарлана.
