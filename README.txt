Тайлбар:
1. Энэ хувилбарт админ хэсгийг хассан.
2. Бүртгэлийн болон асуумжийн хэсэг нэг хуудсан дээр ажиллана.
3. Халдварт бус өвчлөлийн нөлөөлөх хүчин зүйлсийн талаар дэлгэрэнгүй асуултууд нэмсэн.
4. Үр дүн дээр дэлгэрэнгүй зөвлөгөө, тайлбар гарна.
5. Footer хэсэгт "Зохиогч, хөгжүүлэгч: L.BATTSOG." гэж нэмсэн.
6. logo.jpg файл нь толгой хэсэгт ашиглагдана.

GitHub Pages-д байршуулах:
- ZIP-ийг задлаад доторх бүх файлыг repository-ийн root дээр оруулна.
- firebase-config.js файл дотор Firebase config-оо оруулна.
- firebase-rules.txt файлыг Firestore Rules дээр хуулж publish хийнэ.
