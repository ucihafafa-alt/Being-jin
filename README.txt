Биеийн Мэлмий — 30 хоногийн жингийн тэнцвэрийн систем

Ажиллуулах заавар:
1. ZIP файлыг задлана.
2. index.html файлыг нээгээд шууд ажиллуулж болно.
3. GitHub Pages дээр байрлуулах бол бүх файлыг repository дээрээ upload хийгээд Pages асаана.
4. Хүн линкээр орж өөрөө бөглөөд тайлангаа гаргана.
5. Тайлан гарсны дараа "PDF / Хэвлэх" товч дээр дарж PDF болгон хадгалж болно.

Файлууд:
- index.html — үндсэн хуудас, форм, тайлангийн хэсэг
- style.css — дизайн
- app.js — BMI, ангилал, 30 хоногийн төлөвлөгөө гаргах логик
- manifest.json — PWA тохиргоо
- sw.js — offline cache

Анхаарах зүйл:
Энэ систем эмнэлгийн онош тавихгүй. Илүүдэл жинтэй холбоотой анхаарах дохио, дадлын төлөвлөгөө, ерөнхий зөвлөмж гаргана.
