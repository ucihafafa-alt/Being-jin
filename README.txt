Эрүүл Бие — Эрүүл Жин v5

Ажиллуулах:
1. ZIP файлыг задлаарай.
2. index.html файлыг нээхэд шууд ажиллана.

GitHub Pages дээр байрлуулах:
1. ZIP доторх бүх файлыг задлаад repository-ийн хамгийн гадна талд upload хийнэ.
2. index.html, style.css, app.js, manifest.json, sw.js, hero.jpg, balance.jpg, energy.jpg бүгд нэг түвшинд байна.
3. Settings > Pages > Deploy from a branch.
4. Branch: main, Folder: /root сонгоод Save дарна.

v5 засвар:
- Эхний нүүр болон асуумжийн өмнө үнэ, багц, төлбөрийн мэдээлэл гарахгүй.
- Эхлээд зөвхөн асуумж бөглөнө.
- Мэдээллээ үнэн зөв оруулах анхааруулга гарна.
- Биеийн жингийн индекс болон болзошгүй эрсдэлийн тайлан гарна.
- Тайлангийн дараа “Өөрчилмөөр байна / Одоохондоо үгүй” гэсэн 2 сонголт гарна.
- “Өөрчилмөөр байна” сонгосны дараа л 1, 2, 3, 6 сарын багц, үнэ гарна.

Анхаарах:
- Систем өвчин оношлохгүй, эмчилгээ бичихгүй.
- Илүүдэл жин, бэлхүүс, амьдралын хэв маяг, хооллолтын зуршлаас үүдэж болох эрсдэлийг урьдчилсан байдлаар тайлбарлана.
- 6 сарын 20–30 кг зорилт нь баталгаа биш. Хүний эхний жин, зорилт, биеийн онцлог, тууштай байдлаас хамаарна.
