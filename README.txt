Эрүүл Бие — Эрүүл Жин систем

Ажиллуулах:
1. ZIP файлыг задлаарай.
2. index.html файлыг нээхэд шууд ажиллана.

GitHub Pages дээр байрлуулах:
1. GitHub дээр шинэ repository үүсгэнэ. Жишээ нэр: eruul-bie-eruul-jin
2. ZIP доторх бүх файлыг задлаад repository-ийн хамгийн гадна талд upload хийнэ.
   - index.html
   - style.css
   - app.js
   - manifest.json
   - sw.js
   - assets хавтас
   - README.txt
3. Settings > Pages рүү орно.
4. Source: Deploy from a branch
5. Branch: main, Folder: /root сонгоод Save дарна.
6. Хэдэн минутын дараа линк гарна.

Анхаарах:
- Энэ хувилбар static систем тул мэдээллийг серверт хадгалахгүй.
- Хэрэглэгч өөрийн бөглөсөн хураангуйг хуулж page-д илгээнэ.
- Бүрэн 1/2/3 сарын хоолны төлөвлөгөө төлбөр баталгаажсаны дараа гарахаар зориулагдсан.
- Систем өвчин оношлохгүй, эмчилгээний заавар бичихгүй. Халдварт бус өвчлөлийн эрсдэлийн дохиог тайлбарлана.
