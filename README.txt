Эрүүл Бие — Эрүүл Жин v4

Энэ хувилбарын урсгал:
1. Эхний нүүрэнд үнэ, багц, төлбөрийн мэдээлэл харагдахгүй.
2. Хүн үнэгүй БЖИ тодорхойлно.
3. Халдварт бус өвчлөлийн болзошгүй эрсдэлийн дохиогоо уншина.
4. Дараа нь “Төлөвлөгөөний мэдээлэл авах уу?” гэсэн Тийм / Үгүй 2 сонголт гарна.
5. Үгүй гэвэл баяртай мессеж гарна.
6. Тийм гэвэл 1, 2, 3, 6 сарын багц, үнэ, боломжит эрүүл жин бууруулах хүрээ гарна.
