Эрүүл Бие — Эрүүл Жин систем v3

Ажиллуулах:
1. ZIP файлаа задлаарай.
2. index.html файлыг нээхэд шууд ажиллана.

GitHub Pages дээр тавих:
1. Repository руугаа орно.
2. ZIP доторх БҮХ файлыг repo-ийн хамгийн гадна талд upload хийнэ:
   - index.html
   - style.css
   - app.js
   - manifest.json
   - sw.js
   - hero.jpg
   - balance.jpg
   - energy.jpg
   - README.txt
3. Settings > Pages рүү орно.
4. Source: Deploy from a branch
5. Branch: main, Folder: /root сонгоод Save дарна.
6. 2-5 минутын дараа site линк ажиллана.

Шинэчлэлт:
- Нүүр хэсгийн нэр нэг мөр болсон.
- Хүн эхлээд үнэгүй БЖИ тодорхойлно.
- Халдварт бус өвчлөлийн болзошгүй эрсдэлийн дохиог уншина.
- Дараа нь “1–6 сарын багц сонсмоор байна уу?” гэсэн Тийм/Үгүй сонголт гарна.
- Үгүй гэвэл баяртай мессеж гарна.
- Тийм гэвэл нэрээр нь дуудаж, давуу тал/эрсдэлийг тайлбарлаад 1, 2, 3, 6 сарын багц танилцуулна.
- 6 сарын багцыг түр 55,000₮ гэж оруулсан. Өөрчлөх бол app.js дотор packageInfo хэсгээс солино.

Анхаарах:
- Энэ систем өвчин оношлохгүй, эмчилгээ бичихгүй.
- Халдварт бус өвчлөлийн эрсдэлийн дохиог урьдчилсан байдлаар тайлбарлана.
- Бүрэн төлөвлөгөө төлбөр баталгаажсаны дараа гаргах зориулалттай.
